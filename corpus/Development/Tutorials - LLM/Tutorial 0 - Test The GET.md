## 0. Introduction

**Outcome.** By the end of this you've held one GET conversation — read the player roles, brought an idea, picked a role, and saved both the GET's response and the full session to send back.

This is a quick path for a tester on **Claude Code** who just wants to try The GET. No fork, no GitHub account — clone a copy and point Claude Code at the folder.

---

## 1. Skim the published site first

Before you touch any files, browse the web version to get the shape of it: **https://vlabusc.github.io/The-GET/**.

The area that matters most for a first run is **Design → Storytelling** (the page is titled *Situated Player Roles*: The Investigator, The Traveler, The Dreamer, plus Entrant). Read it — it's the heart of how the tutor thinks about an idea.

---

## 2. Get the files

No fork, no GitHub account needed — just clone the public repo:

```
git clone https://github.com/vLabUSC/The-GET.git
cd The-GET
claude
```

(Or download the ZIP from the repo page and open the folder.) You can also **open the folder as a vault in Obsidian** if you'd like to read the pages locally with working links.

---

## 3. Start a session

At the Claude Code prompt, type exactly:

```
Start a GET session.
```

It'll greet you and ask which role you're working in.

---

## 4. Bring an idea and pick a role

Pick a role — The Investigator, Traveler, or Dreamer. Then think of an idea for a project as if for an assignment. Your idea doesn't need to be complete or all sorted out.

---

## 5. Capture the output

Two things when you're done:

- Ask it to **write the full response to a file** in the folder (e.g., *"save this plan to project-plan.md"*).
- Also **save a copy of the whole session** — paste the entire transcript into a text file and send it back. The conversation itself is what's most useful to see.
