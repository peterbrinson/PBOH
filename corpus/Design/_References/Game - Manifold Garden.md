**Developer:** William Chyr Studio | **Year:** 2019 | **Platform:** PC, console
**→ [Steam](https://store.steampowered.com/app/473950/Manifold_Garden/)**

A first-person puzzle game set in an Escher-style infinite architectural space. Architectural detail does triple duty: it orients the player in a disorienting space, conveys object scale and distance, and creates navigation challenges. A reference case for [[Reusing Objects and Spaces]].
