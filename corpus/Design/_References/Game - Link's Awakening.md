**Developer:** Nintendo | **Year:** 1993 (remake 2019) | **Platform:** Game Boy, Switch

A top-down Zelda set on Koholint Island. The hookshot — a quasi-grappling-hook ability — is a canonical "key that is an ability": once Link has it, previously inaccessible spaces (like the bridge at the start of the demo) open up.
