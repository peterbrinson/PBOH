# Peter B's Office Hours

PBOH — Peter B's Office Hours — maps an early idea for a playable story or world, outlining what is known, what questions remain, and how the prototype might be built in a game engine.

---
## [[Get Started]]

Clone or fork the repository, open it with an AI coding agent, and start a session. See **Get Started** for how PBOH works and how to set up the major AI tools (Gemini, Claude Code, Codex, DeepSeek).

The rest below is a browsable copy of the corpus — the same material the guide reads from.
