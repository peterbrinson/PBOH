---
title: "How It Works"
---

You open the repository with an AI coding agent (such as Claude Code or Gemini CLI). The agent reads the whole repository into its working memory and follows the instructions inside to become The GET — the tutor you talk to.

Two things make this possible:

- **Long context** — today's AI models can hold a large amount of text in memory at once, enough to take in the entire repository.
- **In-context learning** — instead of being re-trained, the AI learns what it needs from the material you hand it in the moment. The GET's pages and rules *are* that material.

So the Design and Development sections you can browse here aren't the whole story — they're the library the tutor reads from. The repository is what brings it to life.
